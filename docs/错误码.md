# 算件 API 错误码清单

> 机器可读错误码（收尾三小件之一）。契约测试：`tests/test_error_codes.py`；
> 实现在 `server.py` 的 `_CODE_BY_STATUS` / `ApiError(code=...)`。

## 响应形状

所有错误响应在人话之外带稳定 `code` 字段：

```json
{"error": "口令不对，还剩 4 次机会", "code": "GATE_CODE_REQUIRED"}
```

口径（红线）：

- `code` 是**增量字段**：`error` 人话文案一字不改，老前端只读 `error` 照常工作；
- **成功响应不带 `code`**（该字段只属于错误）；
- 任何错误响应的 `code` 恒为非空字符串——`ApiError` 未显式给码时按 HTTP
  状态码查默认表，表外状态兜底 `HTTP_<状态码>`（如 `HTTP_418`）；
- 码值**稳定**：只增不改不删；同一语义换文案不换码。前端可安全地按码编程。

## 错误码表

| code | HTTP | 触发场景 | 前端处理建议 |
|---|---|---|---|
| `BAD_REQUEST` | 400 | 通用请求校验失败（含引擎 `ValueError`/`TypeError` 校验路径） | 原样展示 `error` 人话 |
| `INVALID_JSON` | 400 | 请求体不是合法 JSON / 不是 JSON 对象 | 属调用方（多为前端自身）问题，提示重试 |
| `CSV_INVALID` | 400 | `/api/ingest/csv` 全链校验失败：内容空 / 解析失败 / 表头缺列 / 行内容非法（带行号）/ 非 UTF-8 / JSON 信封缺 `csv` 字段 | 高亮 CSV 导入入口并展示 `error`（多带行号） |
| `OCR_UNCONFIGURED` | 400 | 识别服务未配置（`data/config.json` 无 `ocr` 段或缺 `key`/`base_url`） | 引导走 CSV 导入 |
| `NUMERIC_OVERFLOW` | 400 | 数字超出可算范围（金额/数量太大或位数太多，`DecimalException`） | 提示拆小再算 |
| `GATE_CODE_REQUIRED` | 401 | 口令门开着：`X-Code` 缺失或不对（本服务的 401 只来自口令门） | 弹口令输入层 |
| `FORBIDDEN` | 403 | Host 不在白名单（防 DNS 重绑定；非局域网 IP 字面量） | 提示须本机/局域网 IP 访问 |
| `NOT_FOUND` | 404 | 接口或静态文件不存在（前端可用 404 做老服务探测） | 提示接口不存在/检查版本 |
| `LENGTH_REQUIRED` | 411 | 请求体用 chunked 传输（本服务只认 Content-Length） | 属调用方问题 |
| `PAYLOAD_TOO_LARGE` | 413 | 请求体超上限（默认 1MB）或图片超 8MB | 提示压缩/拆小再传 |
| `GATE_LOCKED` | 429 | 口令连错 5 次锁定 2 分钟（限速；锁定期对口令也 429） | 展示 `error` 中的锁定时长，禁用口令输入 |
| `RATE_LIMITED` | 429 | 429 兜底（当前无其他来源） | 同上 |
| `INTERNAL_ERROR` | 500 | 服务端内部错误（固定话术，细节只在服务端日志） | 提示稍后重试 |
| `OCR_UPSTREAM_ERROR` | 502 | 识别上游失败（HTTP 错误码 / 网络连不上） | 提示检查网络与密钥，或先用 CSV 导入 |
| `BAD_GATEWAY` | 502 | 502 兜底（当前无其他来源） | 同上 |
| `HTTP_<状态码>` | 其他 | 未登记状态的兜底（如 `HTTP_418`） | 按 HTTP 状态码通用处理 |

## 默认表与显式码的关系

`server.py` 里 `ApiError(status, msg, code=None)`：

- 显式传码（`CSV_INVALID` / `OCR_UNCONFIGURED` / `OCR_UPSTREAM_ERROR` /
  `GATE_LOCKED` / `NUMERIC_OVERFLOW` 等）——需要前端区分语义的场景；
- 不传码——按 `status` 查 `_CODE_BY_STATUS` 默认表（400→`BAD_REQUEST`、
  401→`GATE_CODE_REQUIRED`、404→`NOT_FOUND` ……）。

新增错误码的规矩：**先登记本表 + 补 `tests/test_error_codes.py` 契约用例，
再上 `raise`**；只加码不改语义，需要换语义就换新码（旧的保留映射）。
